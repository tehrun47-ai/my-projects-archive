# SILO Trading Journal — Project Context

## این پروژه چیه؟
SILO یه ژورنال معاملاتی هوشمند (AI-Powered Trading Journal) — یه اپلیکیشن وب برای معامله‌گرها که توش معاملات‌شون رو ثبت می‌کنن، تحلیل می‌کنن، و پیشرفتشون رو مرور می‌کنن.

## برای کی ساخته می‌شه؟
برای **سینا ابراهیمی** — یه مدرس معامله‌گری (Trading Instructor) که برای شاگردهای خودش این ابزار رو می‌خواد.

## نقش من (مصطفی) توی این پروژه چیه؟
من دانشجوی معماری‌ام، دارم این پروژه رو برای استادم (سینا ابراهیمی) با کمک Claude می‌سازم. یعنی من واسط بین Claude و استادم هستم — دستورالعمل‌های استاد رو می‌گیرم (چه توی چت، چه بعداً از طریق GitHub Issues)، به Claude می‌دم، و نتیجه رو (فایل، لینک PR، گزارش) برمی‌گردونم به استاد.

## Stack فنی
- **Frontend:** React + Vite + TypeScript
- **Backend:** Supabase (PostgreSQL + Auth + Storage + Row Level Security)
- **Deploy:** Vercel (متصل مستقیم به GitHub، هر Push به main خودکار Deploy می‌شه)
- **زبان رابط کاربری:** فارسی (RTL)، ولی برند و بعضی متن‌های ثابت (مثل نام SILO) انگلیسی می‌مونن

## اصل مهم: هویت این پروژه چطور شکل گرفته
اولش این پروژه یه فرم ساده‌ی HTML برای ثبت پیش‌از-معامله بود (اسمش هم RTM Trading Journal بود). بعد از یه دور بازطراحی کامل معماری، تبدیل شد به یه اپلیکیشن کامل با اسم جدید **SILO**، با هویت بصری مشخص (ذغالی تیره + گرادیان نارنجی/مرجانی)، و یه‌سری اصول محصولی سخت‌گیرانه که همیشه باید رعایت بشن (فایل `DECISIONS.md` رو ببین).
