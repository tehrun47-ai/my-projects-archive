# My Projects Archive

آرشیو شخصی من (`tehrun47-ai` — مصطفی موسوی) از پروژه‌هایی که با کمک AI (Claude، ChatGPT یا هر ابزار دیگه) کار می‌کنم.

هدف این Repository: هر پروژه یه پوشه‌ی جدا داره، با یه‌سری فایل استاندارد که **کامل و خودکفا** توضیح می‌ده پروژه چیه، تا کجا پیش رفته، چه تصمیم‌هایی گرفته شده، و از کجا باید ادامه داد. این‌جوری هر AI یا آدمی که بخواد کمک کنه، فقط با خوندن این فایل‌ها سریع در جریان کامل قرار می‌گیره — بدون اینکه من مجبور باشم از اول توضیح بدم.
